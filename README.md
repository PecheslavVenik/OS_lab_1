# OS_lab1

## Описание

Лабораторная работа №1 по операционным системам. Вводная работа для знакомства с кросс-платформенной разработкой на C++.

Программа выводит приветствие и определяет текущую операционную систему на этапе компиляции с использованием препроцессорных директив.

## Возможности

- Вывод сообщения "Hello World"
- Автоматическое определение ОС:
  - Windows
  - Linux
  - macOS
  - Unknown OS (для других платформ)
